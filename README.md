# Piano Social

Canale pubblico dell'app Android *Piano Social* (pianificazione dei contenuti social per più clienti).

- `app/` — interfaccia dell'app: l'app installata la scarica da sola (`app/manifest.json`).
- `clienti.json` — elenco clienti con colori, font e logo presi dal marchio di ciascuno.
- `clienti/<cliente>/` — pacchetti contenuti dei clienti pubblicati (per ora nessuno: i contenuti di Lucia stanno in `mikhty999/piano-lucia`).

Generato dal repository privato `social-clienti` (strati 3-adattatori e 4-app): non modificare a mano.
